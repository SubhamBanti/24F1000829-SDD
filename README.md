## Notes App

This project now includes a simple command-line notes app with the following features:

- Add a new note
- View all saved notes
- Search notes using a keyword
- Edit an existing note

## Run the app

Run the Python script directly:
   - `python notes_app.py`


## Files

- `notes_app.py` — main application script
- `run_notes_app.bat` — double-click launcher for Windows
- `my_notes.txt` — saved note data (created when you run the app)
